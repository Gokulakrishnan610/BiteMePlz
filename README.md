# Rec-Kiosk

A comprehensive modern student university management system that enhances and provides a streamlined university experience.

## Project Structure

- `frontend/` - React/Vite frontend application
- `backend/` - Node.js/Express backend server
- `uploads/` - File uploads and static assets

## Getting Started

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
npm install
npm start
```

## Features

- Student management system
- Modern UI/UX design
- Real-time data processing
- Secure authentication
- File upload capabilities

## Technologies Used

- **Frontend**: React, TypeScript, Vite, Tailwind CSS
- **Backend**: Node.js, Express, Supabase
- **Database**: PostgreSQL (via Supabase)
